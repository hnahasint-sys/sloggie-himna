## The system in one picture

```
Shopify (orders come in)
    |
    v
Make.com (6 workflows do the work)
    |
    +--> Google Sheets  (dashboard, auto-updates)
    +--> Asana           (tasks, auto-created)
    +--> Mailchimp        (emails, auto-sent)
    +--> Gmail            (alerts, auto-sent)
```

One sale triggers the whole chain. No manual updates needed.
